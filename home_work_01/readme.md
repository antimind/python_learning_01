# Задания по спискам

## Задание 1. Добавление элемента в список

Дан список:

```python
fruits = ["яблоко", "банан", "апельсин"]
```

Добавьте в конец списка `"груша"` и выведите обновлённый список.

### Пример результата

```text
['яблоко', 'банан', 'апельсин', 'груша']
```

## Задание 2. Изменение и удаление элементов

Дан список:

```python
colors = ["красный", "зелёный", "синий", "жёлтый"]
```

Замените `"зелёный"` на `"белый"`, удалите `"жёлтый"` и выведите получившийся список.

### Пример результата

```text
['красный', 'белый', 'синий']
```

## Задание 3. Сумма, максимум и минимум

Дан список чисел:

```python
numbers = [12, 5, 8, 21, 3, 17]
```

Выведите:

* сумму всех элементов списка;
* максимальное число;
* минимальное число.

### Пример результата

```text
Сумма: 66
Максимум: 21
Минимум: 3
```

## Задание 4. Уникальные элементы

Дан список слов:

```python
words = ["python", "java", "python", "go", "java", "javascript"]
```

Создайте новый список, содержащий только уникальные слова.

Если слово встречается несколько раз, оно должно попасть в новый список только один раз.

Порядок первого появления элементов нужно сохранить.

### Пример результата

```text
['python', 'java', 'go', 'javascript']
```

# Проект: Телефонный справочник. Часть 1

Создайте программу для хранения телефонных контактов.

Все контакты должны храниться в одном списке:

```python
contacts = []
```

Каждый контакт представляет собой отдельный список из имени и номера телефона:

```python
["Анна", "+79991234567"]
```

Например:

```python
contacts = [
    ["Анна", "+79991234567"],
    ["Иван", "+79997654321"]
]
```

## Требования

Программа должна содержать меню:

```text
1. Добавить контакт
2. Показать все контакты
3. Выйти
```

### 1. Добавить контакт

Пользователь вводит имя и номер телефона.

Новый контакт добавляется в список `contacts`.

### 2. Показать все контакты

Программа выводит все сохранённые контакты в удобном виде.

Если список пуст, нужно вывести сообщение:

```text
Список контактов пуст.
```

### 3. Выйти

Программа завершает работу.

Меню должно повторяться до тех пор, пока пользователь не выберет пункт `3`.

## Пример работы программы

```text
1. Добавить контакт
2. Показать все контакты
3. Выйти

Выберите действие: 1
Введите имя: Анна
Введите телефон: +79991234567
Контакт добавлен.

Выберите действие: 2
Анна: +79991234567
```
