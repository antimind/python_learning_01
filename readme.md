# Структура репозитория

Решения заданий находятся в стабильных ветках `hw-{number}`, где `number` - номер домашнего задания.
В ветку `master` ничего не пушить, кроме этого readme больше ничего быть не должно. Разработка ведётся 
в ветках `dev-hw-{number}`, после чего вливается через PR в ветку `hw-{number}`.
